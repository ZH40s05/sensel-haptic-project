# Notices

This repository contains the Sensel integration code, helper scripts,
translations, documentation, and a patch for GNOME Control Center.

The following are intentionally not part of the public Git history:

- GNOME Control Center source trees and downloaded source archives;
- Fedora source RPMs and build outputs;
- the proprietary Sensel Windows control-panel application and its runtime
  files.

The GNOME installer downloads the matching upstream GNOME source archive from
download.gnome.org when a local source tree is not supplied. Upstream
components retain their own copyright and license notices.

Sensel is a trademark of its respective owner. This project is an
independent community integration and is not affiliated with or endorsed by
Sensel.
