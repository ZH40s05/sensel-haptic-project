# 行为准则 / Code of Conduct

本项目希望成为一个友善、清晰、适合协作的社区。参与项目即表示同意在
Issue、Pull Request、讨论和其他项目空间中遵守本行为准则。

This project aims to be a friendly and practical community. By participating,
you agree to follow this code in issues, pull requests, discussions, and
other project spaces.

## 我们提倡 / Expected behavior

- 尊重不同的经验、语言和观点 / be respectful of different experience,
  languages, and viewpoints；
- 针对问题和代码讨论，不针对个人 / discuss the problem or code, not the
  person；
- 提供可复现、可核查的信息，尤其是设备兼容性报告 / provide reproducible,
  verifiable information, especially in compatibility reports；
- 接受善意的修改意见，并在无法确认时明确说明 / accept good-faith
  corrections and state uncertainty clearly；
- 保护隐私，不在公开 Issue 中发布密码、令牌、私有日志或厂商未公开文件 /
  protect privacy and do not post passwords, tokens, private logs, or
  non-public vendor files in public issues。

## 不可接受的行为 / Unacceptable behavior

- 骚扰、歧视、威胁、人身攻击或故意羞辱 / harassment, discrimination,
  threats, personal attacks, or deliberate humiliation；
- 发布他人的私人信息，或诱导他人泄露凭据 / publishing private information
  or inducing someone to disclose credentials；
- 在没有授权的设备上进行破坏性测试 / destructive testing on devices
  without authorization；
- 反复发布无关内容、恶意刷屏或故意阻碍协作 / repeated off-topic posting,
  spam, or deliberate disruption of collaboration。

## 执行 / Enforcement

请将执行问题私下报告给仓库维护者，并附上链接、时间和相关上下文。报告会
被审慎处理；维护者可以编辑、隐藏或删除不符合本准则的内容，也可以限制
继续参与项目的权限。

Report enforcement concerns privately to the repository maintainer with
links, timestamps, and relevant context. Reports will be handled carefully.
The maintainer may edit, hide, or remove content that violates this code,
and may restrict further participation.

本准则参考 Contributor Covenant 2.1 的结构；本项目不复制其完整法律文本。

This code is structured after Contributor Covenant 2.1; the project does not
copy its full legal text.
